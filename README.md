# chatai-wide-screen-enhancer

DeepSeek 网页端宽屏 + 表格显示优化 + 自动折叠深度思考

## 功能

- 📐 **宽屏模式** — 将聊天内容撑满屏幕，告别窄版
- 📊 **表格加宽** — 表格自适应宽度，斑马纹 + 暗色适配
- 🧠 **自动折叠深度思考** — DeepSeek 思考过程自动收起，只看最终回复

## 安装

需要浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) / [ScriptCat](https://scriptcat.org/) 或 [Violentmonkey](https://violentmonkey.github.io/)，然后打开下方的脚本链接安装：

[👉 安装脚本](https://github.com/NBSOD/chatai-wide-screen-enhancer/raw/main/chatai-wide-screen-enhancer.user.js)

## 设置

宽屏与表格优化始终生效，无需配置。点击浏览器工具栏的脚本管理器图标，在 **AI 宽屏优化** 下可操作：

| 菜单项 | 说明 |
|--------|------|
| 🧠 折叠深度思考 | 开关自动折叠（默认开） |
| 🔄 重置折叠状态 | 偶发状态异常时，重新折叠当前会话的所有思考区块 |

> 手动点击某个思考区块的标题栏或箭头后，脚本会交还该区块的控制权，不再自动折叠它。

## 变更

| 版本 | 内容 |
|------|------|
| 1.1.4 | **修正 1.1.3 的方向性错误**：1.1.3 试图由脚本接管表格的横向滚动，实际是在和 DeepSeek 自己的 `.ds-scroll-area` 组件打架（它自带 gutter 和横向滚动条，滚动本来就是它做的）。在真实页面上实测（1920 CSS px 视口、DPR 2）：当前版本把表格外层推右 **317.5px**，虚拟列表 `overflow-x:hidden` 直接吃掉 **304px** —— 这正是「不居中 + 后面的文字被裁」的原因；同时 `width:max-content` 让该表格完全不换行，撑到 **1923px**。现在只做两件事：① 表格改 `width:auto + min-width:100%`（窄表铺满、宽表按需换行，实测 936px → **1469px**，表高 330 → 255）；② 只把外层的盒模型按回来（`box-sizing:border-box`，因为它自带 54px `padding-right`；`margin:0`，抵消 `margin:auto` 在列被撑宽后解出的正值）。**不再改它的 `overflow`、不再抢滚动条、不再打 `.ai-table-wrap` 标记**（`markTableWrappers()` 及相关代码已删除）。实测：候选方案虚拟列表零裁剪；把表格强行撑到 3000px 时，靠它自己的滚动区即可完整滚动查看，仍然零裁剪 |
| 1.1.3 | 修复「表格不居中 / 过长的表格后边文字被裁掉」：横向滚动容器用的是 `div:has(> table)`，**只认 div 父元素**，表格外层一旦不是 `div`（section、grid/居中容器等）滚动规则就静默失效，表格直接溢出消息列，把整页撑宽、列被裁。改动：选择器放宽为 `:has(> table)`（任意标签），并给表格祖先链补 `min-width:0 + max-width:100%`、给滚动容器补 `min-width:0` 与 `align-self/justify-self: stretch`；横向滚动条显式可见；新增 `markTableWrappers()` 打 `.ai-table-wrap`。**（该版本的做法已被 1.1.4 推翻：当时是在本地 fixture 上按推测的结构验证的，没有真实页面；实测真实结构后证明接管滚动的方向是错的。）** |
| 1.1.2 | 修复「发送消息后页面自己往上缩一节、需要手动下拉才能看到刚发的内容和回复」：折叠深度思考会让该区块瞬间变矮，浏览器默认的滚动锚定把这段高度差当成锚点上方内容变化，主动把 `scrollTop` 往回拉。仅在折叠元素上写 `overflow-anchor:none` 无效——浏览器挑中的锚点往往是它下方正在流式输出的正文。现在折叠前后临时关掉**滚动容器**的锚定，并显式修回位置：折叠前停在底部就钉回底部（人留在最新内容处），在读历史则保持折叠区底边在视口中的位置不变（下方正文不跳）。修正用内容坐标反解目标 `scrollTop`，是幂等的，折叠动画或后续重渲染期间重复调用不会叠加位移 |
| 1.1.1 | 修复折叠的静默失效：`hideThinkingEarly` 不再对已标记节点直接短路（虚拟列表回收复用的节点此前会漏折叠）；无 `aria-expanded` 时改用布局探测（`probeCollapsed`）判断真实折叠状态，不再信任可能错位的标记；新增 800ms 点击冷却，杜绝「点击 → 重渲染 → 再点击」反馈环。体验修正：表格改为 `min-width:100% + width:max-content`（原 `width:100%` 会把宽表格压扁换行，与横向滚动互相打架），滚动容器收窄到对话区；表格配色改用中性灰 + 透明度，不再依赖 `prefers-color-scheme`（站内主题与系统主题并不一致）；表格样式整体收窄到对话区；设置读取做类型归一化；菜单项在无法注销的管理器上不再重复堆积；新增关键选择器失效的启动自检 |
